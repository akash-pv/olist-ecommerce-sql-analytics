# Dataset Source

## Brazilian E-Commerce Public Dataset by Olist

**Source:** Kaggle

**Dataset link:** https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

### Dataset Description

This project uses the Brazilian E-Commerce Public Dataset provided by Olist.

The dataset contains anonymised information about e-commerce orders, customers, sellers, products, payments, reviews, and delivery operations.

### Tables Used

- customers
- orders
- order_items
- payments
- products
- sellers
- reviews
- category_translation

### Dataset Period

2016–2018 (data ends on 17 October 2018).

### Usage

The dataset is used for educational and portfolio purposes to practise SQL querying, data analysis, and business problem-solving.
